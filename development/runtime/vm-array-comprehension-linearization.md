# VM Array Comprehension Linearization

## Problem

VM array comprehensions currently compile to an empty array accumulator followed by `APPEND` for every emitted item. The VM `APPEND` instruction preserves immutable-style behavior by copying the full list before adding the new item. That is correct for public append semantics, but it makes compiler-generated comprehensions quadratic for large inputs.

## Target

Add an internal VM accumulator path for array comprehensions so generated bytecode appends results in place while preserving the public behavior of ordinary `APPEND` and `+=`.

## Implementation

Array comprehensions now compile to internal `ARRAY_BUILDER_INIT`, `ARRAY_BUILDER_ADD`, and `ARRAY_BUILDER_FINISH` instructions. The public `APPEND` instruction keeps copy-preserving semantics.
